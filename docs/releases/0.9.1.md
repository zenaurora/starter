# Starter 0.9.1

2026-11-20 · 软件更新入口交互修复。

## 修复

- 修复点击应用更新入口后 Starter 仍留在前台、缺少反馈，导致操作看似没有响应的问题。
- 将「在应用中更新」改为「打开应用检查更新」，明确此操作会打开原应用，实际检查和安装仍由原应用完成。
- 打开应用或更新页面后自动收起 Starter，保留软件更新列表和下一步提示；打开应用失败时留在面板显示具体原因。
- 关闭操作菜单时释放菜单订阅，避免后续菜单关闭事件重新抢回焦点。

## 验证

- 格式检查、Clippy 和 `cargo test --locked --all-targets` 通过。
- 新增界面回归测试，覆盖应用打开成功与失败、操作文案、更新页面跳转和窗口交接事件。
