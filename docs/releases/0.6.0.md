# Starter 0.6.0

2026-10-14 · 系统资源监控、macOS 全屏呼出修复和搜索性能优化。

## 系统资源监控

- 新增“监控”面板，搜索 `monitor`、`监控`，或输入 `/monitor` 即可打开。
- 展示整机 CPU、内存和启动盘容量，以及按应用聚合的进程资源占用；支持按名称筛选、按 CPU 或内存排序。
- 面板打开时每秒采样，磁盘容量每 15 秒刷新；离开面板、隐藏启动器或打开设置后暂停采样。
- CPU 百分比以整机为 100%；应用内存按驻留内存求和，可能包含共享页面。磁盘指标为容量占用。

## macOS 全屏呼出

- 使用非激活 NSPanel 和原生窗口显示、隐藏路径，在当前全屏 Space 上呼出并获取键盘焦点。
- 将面板层级调整为浮动窗口层级，保留中文输入法候选框和组合输入路径。
- 新增真实全屏快捷键、焦点恢复及中文输入回归脚本，运行需要终端的辅助功能权限。

## 性能优化

- 保留热文件索引和文件名缓存，减少重复路径、父目录字符串和搜索时的整表克隆。
- 排名分批保留前 100 个候选；内置命令只构造一次。纠错仅对 4–31 字符查询启用，找到第一个容差内匹配后返回，减少额外距离计算。
- 文件名查询移除固定 50 ms 等待；内容搜索继续保留去抖与取消机制。
- 监控虚拟列表共享不可变快照，减少逐帧复制；后续任务调度时回收已完成的异步任务句柄。
- 同机约 10 万条索引微基准中，索引保留的 Rust 堆从 47.23 MiB 降至 25.56 MiB。这不代表整个应用的 RSS；完整数据及测量边界见[性能优化记录](../优化路线.md)。
