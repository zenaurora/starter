# Starter 0.4.0

2026-10-10 · 本文列出相较于 0.3.0 的全部功能更新和配置变化。

## 快捷键与应用打开

- 一个全局快捷键可以同时打开多个应用，例如 `Cmd+Enter` 打开 kitty 和 ChatGPT。各应用独立启动，其中一个失败时仍会尝试打开其他应用，并显示失败原因。
- 应用快捷键支持新增、编辑、删除和单独启用或停用。旧的单应用快捷键配置自动兼容为应用列表。
- 快捷键设置改为总览和独立编辑器：分别管理“呼出 Starter”和应用快捷键组，编辑时明确显示按键组合及目标应用；取消编辑只丢弃当前组的修改。
- 使用可搜索的按键选择框配置组合，支持 Cmd/Win、Ctrl、Option/Alt、Shift、字母、数字、方向键和功能键。保存时检查重复组合、空按键和缺少修饰键，注册失败或保存失败时恢复原快捷键。
- 移除内置“打开终端”入口、专用终端设置、托盘菜单项及默认终端快捷键。kitty、Terminal 等终端应用通过普通应用快捷键自行配置。
- 新增文件打开方式设置：为扩展名、文件夹及默认规则选择应用，可搜索已安装应用或选择路径。规则只影响从 Starter 打开文件的行为。

## 开机自启动

- 新增“设置 → 启动 → 开机自启动”，默认关闭，保存后生效，取消不改变系统登记。
- 启用后，登录系统时自动运行 Starter 并驻留托盘；搜索窗口通过呼出快捷键或托盘打开。
- macOS 使用当前用户的 LaunchAgent，Windows 使用当前用户的 Run 注册表项，登录启动时传入 `--background`。
- 保存失败时恢复原自启动状态；启动过程中出现错误时仍显示错误窗口。

## 中文输入与窗口

- 修复 macOS 系统拼音候选框在搜索框和设置输入框中不显示的问题，启动器窗口改为可激活的浮动窗口。
- 保留跨桌面和全屏空间呼出的窗口属性。
- 中文组合输入期间，方向键、回车和 Esc 交给输入法处理，避免选字时触发启动器操作。

## 剪贴板历史

- 新增 `/clip` 模式，支持检索和恢复文本、链接、图片及文件记录；图片显示缩略图，支持按类型和复制日期筛选。
- 历史保存在本机，保留最近 30 天、最多 200 条，总量上限 100 MiB，单条上限 16 MiB；重复内容去重。
- 设置页可以暂停记录或清空历史，支持删除单条记录。系统标记为私密或临时的内容不记录。
- 文件记录保留原路径，原文件移动或删除后无法再次复制；清空操作需确认。

## 应用卸载

- 新增 `/uninstall` 模式，通过搜索选择应用并确认卸载。
- macOS 将应用移到废纸篓，可恢复；Windows 调用应用官方卸载入口。
- 检查应用身份和路径，防止卸载 Starter 自身或把链接误当作应用处理。

## 系统命令与提醒

- 搜索支持中英文系统命令，包括锁屏、睡眠、重启和关机；重启、关机执行前需确认。
- 支持搜索蓝牙、显示等系统设置入口，并提供系统模式和托盘入口。
- 新增本地提醒，可用 `/remind 10m 开会`、`/remind 明天 15:00 开会` 等输入快速创建，也可在提醒面板中管理。
- 支持相对时间、今天／明天／后天、具体日期和中英文时间表达；提醒记录持久保存，到期通过系统通知提示。
- 程序重新启动或电脑从睡眠恢复后处理已到期提醒，避免重复发送。发送通知时 Starter 需要保持运行。

## 自动更新

- 设置页提供自动检查更新、手动检查及“下载并更新”；自动检查在启动时及运行期间每 24 小时执行。
- 下载显示进度并支持取消，校验包大小、完整性及 SHA-256，按系统和架构选择对应安装包。
- macOS 使用 DMG，Windows 安装版使用 MSI、便携版使用 ZIP。更新后自动重新启动，保留配置和使用记录。
- 应用替换或新版本启动失败时执行回滚；更新期间避免重复检查和并行安装。
- 版本号统一更新为 0.4.0，包括应用内版本、Cargo 元数据和 macOS 应用包。发布流程使用本文件作为 GitHub Release 更新说明。

## 配置兼容与验证

- 保留主题、搜索目录、别名、收藏、使用记录和已有应用快捷键。旧 `application` 字段兼容为 `applications` 列表。
- 旧 `terminal`、`terminal_hotkey` 字段不再生效，读取时忽略，之后保存设置时移除；不会自动生成终端快捷键，请自行添加所需应用组合。
- 旧配置没有 `launch_at_login` 字段时，自启动默认关闭。
- 格式检查、Clippy 和 61 项测试通过，覆盖配置兼容、快捷键与自启动回滚、文件规则、更新安装、剪贴板、卸载和提醒。
- 本机已校验 macOS 自启动登记文件，并构建、安装 macOS Apple Silicon 版本。Windows 自启动模块的交叉编译检查通过；完整 Windows 应用和实际登录启动需要在 Windows 环境验证。
