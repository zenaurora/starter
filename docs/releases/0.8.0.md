# Starter 0.8.0

2026-10-29 · 常用收藏、轻量待办、端口排查与命令发现。

## 常用收藏

- 新增常用收藏工作台，直接输入或粘贴内容即可保存，也可一键收藏剪贴板文本。
- 无需选择分类或填写名称，名称自动取自内容首行，需要时再编辑。
- 支持多行文本、链接识别、搜索、置顶、复制和删除撤销；收藏也能加入待办。
- 使用 `⌘Enter` / `Ctrl+Enter` 快速收藏，普通 Enter 保留换行；中文输入法组词时不会误提交。
- 强化按钮悬停、按下、保存中和复制后的反馈，保存失败会保留草稿。

## 轻量待办

- 新增待办工作台，输入后按 Enter 添加，点击圆圈完成或恢复。
- 支持搜索、完成状态筛选、编辑、置顶和删除撤销，与定时提醒独立。
- 收藏与待办仅保存在本机，后台串行写入并原子替换；读取失败时保留原文件并提供重试入口。

## 端口排查

- 新增端口排查工作台，查看当前用户可见的 TCP 监听与 UDP 绑定，按端口、进程名称或 PID 查找。
- 显示监听地址与进程信息，支持复制地址、PID 和程序路径。
- 核实进程身份后提供终止或强制结束操作，执行前显示确认；无法核实身份时仅允许查看和复制。
- 按需扫描，支持手动刷新，空闲时不持续轮询。

## 命令与交互

- 输入 `/` 可浏览全部功能和系统命令，继续输入英文前缀或中文名称筛选，使用方向键与 Enter 打开。
- 新增 `/save`、`/todo` 和 `/ports` 命令，可直接带入搜索或待办内容。
- 首页增加工作台入口，改善面板切换、焦点恢复和中文输入处理。
