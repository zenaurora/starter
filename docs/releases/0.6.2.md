# Starter 0.6.2

2026-10-17 · 增强资源监控中的进程操作和交互体验。

## 资源监控

- 支持通过 Enter、⌘/Ctrl+K、右键和行末操作按钮打开进程操作菜单。
- 支持正常退出、终止进程、强制退出、在 Finder/资源管理器中显示和复制路径。
- 终止进程和强制退出增加确认流程，操作结果和失败原因会保留在菜单中。
- 操作前重新校验 PID、启动时间和可执行文件，避免监控刷新或 PID 复用导致误操作。
- 监控列表支持稳定的键盘选择、排序、筛选、自动滚动和实时刷新；悬停颜色跟随当前主题。

## 验证

- `cargo check --all-targets`
- `cargo test --locked --all-targets`：核心库 60 项通过，UI 37 项通过；已有的菜单焦点回环测试仍失败。
