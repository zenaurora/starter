# Starter 0.7.0

2026-10-28 · 本机软件更新、来源检测与交互改进。

## 本机软件更新（macOS）

- 新增内置软件更新面板，可从首页或搜索 `/update`、`软件更新` 打开，无需外部更新脚本。
- 直接读取 Homebrew、npm/pnpm/Bun 全局包、uv tool、pipx、Cargo 和 rustup 的安装记录，区分不同安装环境和软件来源。
- 自动后台检测受支持的软件版本，支持 Sparkle appcast、App Store 公开接口及严格匹配的 Homebrew Cask 目录；独立命令行工具按已确认的安装方式提供自更新。
- 右键即可更新单个软件；多选后提供批量更新预览，按项执行并保留结果，失败或中断后停止后续任务。保留原安装参数、版本约束和 Homebrew 固定状态。
- 内嵌终端支持查看输出、输入与中断；需要原应用、App Store 或系统设置处理的更新提供对应入口，未确认的来源会明确说明。

## 界面与提示

- 软件列表使用统一列宽与虚拟化布局，改善长名称、长版本号和窗口边缘的排版。
- 应用复用本机图标，右键菜单按操作分组，并支持键盘导航和窗口边缘避让。
- 来源检查提示可以展开查看具体原因，区分检查失败、来源待确认和未检查。
- 修复新版 Bun 空全局包清单被误报为读取失败的问题。

## 性能与维护

- 复用应用清单与图标缓存，缓存本地和在线检测结果，限制检测并发、输出体积与网络读取大小。
- 公开应用目录流式解析，后台刷新保留选中项与滚动位置；更新开始时取消进行中的扫描。
- 终端按需创建，返回列表后释放缓冲；检测进程支持超时与取消回收，减少重复扫描和空闲开销。
- 补充软件来源协议、支持范围与限制说明。Windows 保留现有功能，本次软件更新面板仅在 macOS 提供。

## 下载

- macOS Apple Silicon：`Starter-0.7.0-macos-arm64.dmg`
- macOS Intel：`Starter-0.7.0-macos-x86_64.dmg`
- Windows x64：MSI 安装包或便携 ZIP。
