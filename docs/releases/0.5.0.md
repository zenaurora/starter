# Starter 0.5.0

2026-10-12 · 全屏 Space overlay、Mole 卸载任务面板和启动器稳定性更新。

## macOS 全屏窗口

- 启动器窗口继续使用可激活的 Floating panel，保留 macOS 拼音候选框和中文组合输入能力。
- macOS 13 及以上使用 `CanJoinAllApplications`，并结合 `CanJoinAllSpaces` 与 `FullScreenAuxiliary`，让启动器出现在当前应用或全屏 Space 上。
- 修复全屏 Space 切换时窗口短暂失活导致的闪烁、第一次呼出失败和需要再次按快捷键的问题。
- 失活关闭增加短暂复核窗口，重新激活或再次呼出会取消过期的关闭任务。

## 应用卸载

- macOS 卸载流程内置 Mole 风格的任务终端，不再打开用户正在使用的 Kitty、Terminal 或其他终端应用。
- 卸载前展示待删除的应用文件、配置和数据，支持确认、取消、停止和恢复焦点。
- 对系统级路径、活动应用和无效应用身份进行保护，并保留原生废纸篓卸载作为回退路径。

## 验证

- `cargo fmt --check`
- `cargo clippy --locked --all-targets -- -D warnings`
- `cargo test --locked --all-targets`
- macOS 全屏 host probe、release bundle 签名和应用包安装验证通过。
