# Starter 0.6.1

2026-10-14 · 更新下载流程提示和网络连接反馈。

## 更新体验

- 更新页面增加真实下载进度条，显示已下载大小和百分比。
- 将更新过程拆分为连接服务器、下载、SHA-256 校验、准备安装和启动安装助手几个阶段，并分别显示状态。
- 连接阶段增加 15 秒连接超时，网络或代理不可用时更快显示错误。
- 错误提示明确指出 GitHub 网络或代理配置可能需要检查。
- 连接、下载、校验和准备安装阶段都可以取消更新。

## 验证

- `cargo fmt --check`
- `cargo clippy --offline --locked --all-targets -- -D warnings`
- `cargo test --offline --locked --all-targets`
