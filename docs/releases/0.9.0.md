# Starter 0.9.0

2026-11-06 · 依赖升级与系统监控改进。

## 依赖升级

- 将 GPUI Kit 升级至 0.9、global-hotkey 升级至 0.9、sysinfo 升级至 0.40，并更新终端解析、配置解析、加密摘要、Windows 注册表和 ZIP 处理依赖。
- 更新锁定文件中的间接依赖；移除旧 GPUI 图形栈中不再使用的 Objective-C 桥接依赖，消除 `block 0.1.6` 的 future-incompatibility 编译提示。
- 最低 Rust 版本调整为 1.98，以匹配新版 GPUI 所使用的稳定标准库 API。

## 监控与兼容性

- 系统监控继续只采集进程 CPU、内存和可执行文件路径，明确启用已退出进程清理，避免保留失效进程记录。
- 磁盘刷新只读取容量信息，并在每次刷新时清除已卸载磁盘；首次进入监控即采集容量，避免首屏显示为零。
- 更新 sysinfo、终端尺寸和滚动事件等 API 调用，保持现有快捷键显示、摘要格式和更新校验行为。

## 验证

- Rust 1.98 编译检查、macOS 构建、Clippy 和格式检查通过。
- `cargo test --locked --all-targets` 通过，共 207 项测试。
- Windows 业务代码独立类型检查通过；完整 Windows 安装包由发布工作流构建与验证。
